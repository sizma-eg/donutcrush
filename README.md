# Donut Crush — E-commerce Frontend

This is the first production-oriented frontend layer for Donut Crush.

## Current
- Responsive storefront
- Brand colors: pink + brown
- Real uploaded donut photos + logo
- Product cards and categories
- Search
- Cart with localStorage
- Cash on Delivery messaging
- Instagram link
- Mobile-friendly layout
- Prepared for API/backend integration

## Next backend layer
- Cloudflare Workers API
- Cloudflare D1 database
- Admin authentication
- Product CRUD
- Orders CRUD/status
- Customer checkout
- Delivery-area configuration
- Real checkout -> database flow

## GitHub Pages
Upload `index.html` and the `assets` folder to your repository. GitHub Pages can host this frontend.

Product data is currently seeded in the JavaScript inside `index.html`; it will be replaced by the API after the backend is connected.
